# Google Sheets Lifestyle Tracker

## Overview

A structured spreadsheet workflow designed to organize everyday activities, schedules, goals, categories, and progress.

## Features

* Multi-tab organization
* Activity tracking
* Goal tracking
* Category management
* Data validation
* Spreadsheet formulas
* Progress tracking
* Structured reference data

## Suggested Workbook Structure

### Dashboard

Provides a high-level view of tracked information and progress.

### Activities

Records activities, dates, categories, status, and notes.

### Goals

Tracks goals, target dates, progress, and completion status.

### Reference Data

Contains standardized categories and validation lists.
